Kurulum

  1. ZIP’i tamamen çıkartın.
  2. Chrome adres çubuğuna chrome://extensions yazın.
  3. Geliştirici modu seçeneğini açın.
  4. Paketlenmemiş öğe yükle ile paketteki extension klasörünü seçin.
  5. Müzik çalan sekmede Amber VU simgesine tıklayın.

YTM AI Blocker ile aynı anda çalışmama sorunu biliniyor; deneme sırasında diğer eklentiyi kapatın. Windows’ta canlı YouTube doğrulaması henüz tamamlanmadı.

Install

  1. Extract the entire ZIP.
  2. Open chrome://extensions in Chrome.
  3. Enable Developer mode.
  4. Choose Load unpacked and select the included extension folder.
  5. Play music in a web tab and click the Amber VU icon.

Disable YTM AI Blocker while testing. Real YouTube capture on Windows is awaiting live verification.

No server, Python or terminal is needed to use the extension. The launcher opens this guide; Chrome installation remains manual.
